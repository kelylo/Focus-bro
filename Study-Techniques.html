The learner's toolkit

Study less.
Remember more.

Pick the method that matches the job. Learn the difference between taking information in, retrieving it, explaining it, and applying it.

01

Active recall

Pull the answer from memory before looking at the source. The effort is the learning.

  • Study one small section.
  • Close it and write everything you remember.
  • Check, correct, and schedule the next attempt.
Prompt: “What are the three ideas I can explain without looking?”
02

Spaced repetition

Review just before forgetting so each session strengthens the memory.

  • Review today, tomorrow, then 3, 7 and 14 days later.
  • Use one question and one answer per card.
  • Schedule the next review before you stop.
Rule: difficult cards return sooner; easy cards spread out.
03

Feynman method

Explain a concept in plain language, locate the gap, and simplify it again.

  • Choose one narrow idea.
  • Teach an imaginary beginner.
  • Return to the source only for the gaps.

04

Interleaving

Mix related problem types so you learn when and why to use each skill.

  • Practise two or three related skills.
  • Change the problem type every few questions.
  • Ask what signal tells you which method to use.
Finish with one unfamiliar problem to test transfer.
